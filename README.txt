Fire hotspots team map

Extract the entire ZIP to a folder before starting. You need Python 3.11 or newer and an internet connection.

Windows: double-click Start Weather Map.cmd. Mac or Linux: open a terminal in the extracted folder and run python3 weather_server.py.

Enter the shared Meteomatics challenge username and password when prompted. The password is hidden as you type. Alternatively set METEOMATICS_USER and METEOMATICS_PASSWORD in your environment. Keep the terminal open while using the map. The browser opens automatically. If needed, paste the printed Local fire map address into your browser.

Temperature & wind starts enabled below the zoom buttons. Weather comes from the team's Meteomatics account. Fire detections are the included GeoJSON snapshot. Each teammate runs their own local server. Close the terminal to stop it.
